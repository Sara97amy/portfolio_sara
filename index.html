Projektuppgift hemsida

ZooSAL är en fiktiv djurparkswebbplats byggd enbart i HTML och CSS som ett skolprojekt i grupp. Sidan presenterar parken med sektioner för djur, restauranger, lekplats, öppettider och karta — allt strukturerat för att ge en realistisk besöksupplevelse.

Vi jobbade i ett team med Git och GitHub för versionshantering och delade upp arbetet i feature-branches med pull requests. Vi granskade varandras kod löpande och löste merge-konflikter, vilket gav en praktisk introduktion till ett verkligt utvecklingsflöde.

Projektet lärde mig grunderna i semantisk HTML-struktur och CSS-layout, samt hur man arbetar strukturerat i grupp med versionshantering från start.

Web API

Web API för bloggportal

Blog Portal Web API är ett REST API byggt i C# med ASP.NET Core som backend för en bloggplattform. API:et hanterar blogginlägg, kategorier, kommentarer och användare.

Projektet följer en klassisk skiktad arkitektur med Controllers, Services, Repositories och DTOs — vilket håller affärslogik och dataaccess separerade. Databasen hanteras via Entity Framework Core med Migrations mot SQL Server, och autentisering sköts med JWT-tokens för att skydda endpoints.

Genom projektet fick jag praktisk erfarenhet av att strukturera ett API från grunden, arbeta med relationsdata i SQL Server och implementera säker autentisering med JWT.

Console applikation

Interaktivt spel

Shotgun var mitt allra första C#-projekt — en konsollapplikation där spelaren tävlar mot datorn genom att välja en action varje runda: ladda, skjuta, skjuta med hagelgevär eller blockera — där varje val kräver rätt mängd ammunition och tajming för att vinna.

Projektet är strukturerat med separata klasser för spellogik, spelarhantering och action-typer — vilket håller ansvar tydligt separerat. Datormotståndaren använder villkorsstyrd logik baserad på ammunitionstillstånd, och spelet kör i en loop där båda spelarna avslöjar sitt val simultant varje runda.

Genom projektet övade jag objektorienterad design i C#, att dela upp logik i flera klasser med tydliga ansvarsområden samt att hantera spelstatus och villkorsstyrt flöde i en interaktiv konsollapplikation.
